LC Valid Sudoku Constraint tracking with Sets
Problem BankDay 4

LeetCode

Valid Sudoku

Check whether a partially filled 9x9 Sudoku board violates any row, column, or 3x3 box rule.

PatternConstraint tracking
TimeO(1) for fixed 9x9
SpaceO(1) for fixed 9x9

Interpretation

For each non-empty cell, check whether the same value has already appeared in the same row, same column, or same 3x3 box.

Set-Based Solution

O(1)
def is_valid_sudoku(board):
    rows = set()
    cols = set()
    boxes = set()

    for r in range(9):
        for c in range(9):
            value = board[r][c]

            if value == ".":
                continue

            row_key = (r, value)
            col_key = (c, value)
            box_key = (r // 3, c // 3, value)

            if row_key in rows or col_key in cols or box_key in boxes:
                return False

            rows.add(row_key)
            cols.add(col_key)
            boxes.add(box_key)

    return True

Key Idea

r // 3 and c // 3 identify the 3x3 box group. The value is included in the key so different numbers in the same box are allowed, but duplicate numbers are rejected.

Interview Answer

"I use three Sets to track values seen in rows, columns, and 3x3 boxes. For each non-empty cell, I create a row key, column key, and box key. If any key already exists, the board is invalid. Since the board is fixed at 9x9, time and space are O(1)."
