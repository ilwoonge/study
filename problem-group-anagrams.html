Group Anagrams

Group words together if they are anagrams of each other.

PatternNormalized key
TimeO(n * k log k)
SpaceO(n * k)

Interpretation

Anagrams contain the same characters with the same counts. If we sort each word, anagrams produce the same sorted string, which can be used as a HashMap key.

Solution Without defaultdict

Sorted key
def group_anagrams(strs):
    groups = {}

    for word in strs:
        key = ''.join(sorted(word))

        if key not in groups:
            groups[key] = []

        groups[key].append(word)

    return list(groups.values())

Key Lines

sorted(word) returns a sorted list of characters. ''.join(...) converts that list back into a string. We use list(groups.values()) because groups.values() returns a dict_values view, not a real list.

Interview Answer

"I use a dictionary where the key is the sorted version of each word, and the value is a list of words that share that key. Since anagrams have the same characters, sorting them produces the same key. I append each word to its group and return all dictionary values as a list. The time is O(n * k log k)."
