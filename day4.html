LeetCode 1

Valid Sudoku

We do not solve the Sudoku. We only check whether the filled cells violate row, column, or 3x3 box rules.

Board Mental Model

board[r][c] means the value at row r and column c. The same value cannot appear twice in the same row, same column, or same 3x3 box. 

row check:    (r, value)
column check: (c, value)
box check:    (r // 3, c // 3, value)

Set-Based Solution

Fixed board: O(1) 
def is_valid_sudoku(board):
    rows = set()
    cols = set()
    boxes = set()

    for r in range(9):
        for c in range(9):
            value = board[r][c]

            if value == ".":
                continue

            row_key = (r, value)
            col_key = (c, value)
            box_key = (r // 3, c // 3, value)

            if row_key in rows or col_key in cols or box_key in boxes:
                return False

            rows.add(row_key)
            cols.add(col_key)
            boxes.add(box_key)

    return True

Why // Works

r // 3 and c // 3 find the 3x3 box group. Rows 0, 1, 2 map to group 0, rows 3, 4, 5 map to group 1, and rows 6, 7, 8 map to group 2.

Interview Sentence

"I use three Sets to track values seen in rows, columns, and 3x3 boxes. For each non-empty cell, I create a row key, column key, and box key. If any key already exists, the board is invalid."

LeetCode 2

Encode and Decode Strings

Convert a list of strings into one string and decode it back without losing information, even if a string contains separators.

Why Delimiters Alone Fail

",".join(strs) fails when original strings contain commas. Length-prefix encoding is safer because the decoder reads an exact number of characters for each string.

Length-Prefix Solution

Time O(n) 
def encode(strs):
    result = ""

    for s in strs:
        result += str(len(s)) + "#" + s

    return result


def decode(s):
    result = []
    i = 0

    while i < len(s):
        j = i

        while s[j] != "#":
            j += 1

        length = int(s[i:j])
        word_start = j + 1
        word = s[word_start:word_start + length]

        result.append(word)
        i = word_start + length

    return result

Example

["he#llo", "world"]

encode -> "6#he#llo5#world"

decode reads:
6 characters -> "he#llo"
5 characters -> "world"

Interview Sentence

"I use length-prefix encoding. For each string, I store its length, a separator, and the string. During decoding, I read the length first and then read exactly that many characters."

HTTP Methods, Status Codes, and API Contracts

A good API design clearly defines how clients communicate with the server, what data is required, what response is returned, and how errors are represented.

HTTP Methods

GETRead or retrieve data.
POSTCreate data or trigger an action.
PUTReplace an entire resource.
PATCHUpdate part of a resource.
DELETEDelete a resource.

Status Codes

200OK: request succeeded.
201Created: new resource was created.
400Bad Request: invalid client input.
401Unauthorized: authentication is missing or invalid.
403Forbidden: authenticated but not allowed.
404Not Found: resource does not exist.

Must-Memorize Q&A

Concepts You Should Be Able to Say Out Loud

What does board[r][c] mean?

It means the value at row r and column c.

What does r // 3, c // 3 identify?

It identifies which 3x3 Sudoku box the current cell belongs to.

Why is delimiter-only encoding unsafe?

The delimiter can appear inside the original string, making decoding ambiguous.

Why is length-prefix encoding safe?

The decoder reads the length first, then reads exactly that many characters.

What is the difference between PUT and PATCH?

PUT replaces the whole resource, while PATCH updates part of the resource.

What is the difference between 401 and 403?

401 means not authenticated. 403 means authenticated but not allowed.
