Evaluate Reverse Polish Notation

Evaluate an expression where operators appear after operands. Use a stack to combine the most recent values whenever an operator appears.

PatternStack
TimeO(n)
SpaceO(n)

Interpretation

A number is not immediately calculated, so it is pushed onto the stack. An operator means the previous two numbers are ready to be combined. 

tokens = ["2", "1", "+", "3", "*"]

2 1 + 3 *
= (2 + 1) * 3
= 9

Optimized Solution

O(n)
def evalRPN(tokens):
    stack = []

    for token in tokens:
        if token not in "+-*/":
            stack.append(int(token))
        else:
            b = stack.pop()
            a = stack.pop()

            if token == "+":
                stack.append(a + b)
            elif token == "-":
                stack.append(a - b)
            elif token == "*":
                stack.append(a * b)
            else:
                stack.append(int(float(a) / b))

    return stack[0]

Walkthrough

tokens = ["4", "13", "5", "/", "+"]

4  -> [4]
13 -> [4, 13]
5  -> [4, 13, 5]
/  -> 13 / 5 = 2, stack = [4, 2]
+  -> 4 + 2 = 6, stack = [6]

Common Bug

If you write a = stack.pop() first and then calculate a - b, subtraction and division will be reversed. Pop into b first, then a. 

b = stack.pop()
a = stack.pop()

result = a - b
result = a / b

Division Rule

Division must truncate toward zero. This is different from Python's floor division for negative numbers. 

6 / -132 = -0.045...
correct result = 0

6 // -132 = -1  # wrong for this problem

Interview Answer

"I process each token once. Numbers are pushed onto the stack. When I see an operator, I pop the right operand first, then the left operand, calculate the result, and push it back. The final stack value is the answer."
