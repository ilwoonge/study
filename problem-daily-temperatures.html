Daily Temperatures

Return how many days each temperature must wait until a warmer day appears. Use a monotonic stack to solve it in one pass.

PatternMonotonic Stack
TimeO(n)
SpaceO(n)

Interpretation

For each day, we need to know the next future day with a higher temperature. The stack stores indexes for days whose answer has not been found yet. 

temperatures = [73, 74, 75, 71, 69, 72, 76, 73]
answer       = [ 1,  1,  4,  2,  1,  1,  0,  0]

Optimized Solution

O(n)
def dailyTemperatures(temperatures):
    answer = [0] * len(temperatures)
    stack = []

    for i, temp in enumerate(temperatures):
        while stack and temp > temperatures[stack[-1]]:
            prev_index = stack.pop()
            answer[prev_index] = i - prev_index

        stack.append(i)

    return answer

Walkthrough

i = 0, temp = 73
stack = [0]

i = 1, temp = 74
74 > temperatures[0]
answer[0] = 1 - 0 = 1
stack = [1]

i = 2, temp = 75
75 > temperatures[1]
answer[1] = 2 - 1 = 1
stack = [2]

Why the Stack Is Monotonic

The stack keeps indexes whose temperatures are waiting for a warmer value. From bottom to top, those unresolved temperatures are in decreasing order. When a warmer value arrives, it resolves one or more previous indexes.

Complexity

Time is O(n) because each index enters and leaves the stack at most once. Space is O(n) because the stack may hold many unresolved days.

Interview Answer

"I use a monotonic stack of indexes. When the current temperature is warmer than the temperature at the index on top of the stack, I pop that index and set its answer to the difference between the current index and the popped index."
