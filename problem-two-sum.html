Two Sum

Given an array and a target, return the indices of two numbers that add up to the target.

PatternHashMap lookup
TimeO(n)
SpaceO(n)

Interpretation

For each number, ask: "What other number do I need to reach the target?" That needed number is target - num. If we have already seen it, we can return both indices.

Optimized Solution

O(n)
def two_sum(nums, target):
    seen = {}

    for i, num in enumerate(nums):
        need = target - num

        if need in seen:
            return [seen[need], i]

        seen[num] = i

Walkthrough

For nums = [2, 7, 11, 15] and target = 9, when we see 2, we need 7, but it is not in the map. We store 2 -> 0. When we see 7, we need 2, which is already stored, so we return [0, 1].

Interview Answer

"I use a HashMap to store numbers I have already seen and their indices. For each number, I compute the complement as target minus the current number. If the complement exists in the map, I return its index and the current index. Otherwise, I store the current number. This takes O(n) time and O(n) space."
