Data Structure

Stack

A stack is a Last-In, First-Out data structure. The last value that gets pushed is the first value that gets popped.

LIFO

bottom [1, 2, 3] top

pop() returns 3
pop() returns 2
pop() returns 1

Python Stack Operations

stack.append(x)Push a value onto the stack.
stack.pop()Remove and return the top value.
stack[-1]Peek at the top value without removing it.
not stackCheck whether the stack is empty.

When to Use a Stack

Use a stack when the most recent item must be handled first: bracket matching, undo/redo, nested structures, previous states, and monotonic stack problems.

LeetCode 1

Valid Parentheses

Check whether brackets are closed in the correct order. The most recent opening bracket must match the next closing bracket.

Stack Solution

Time O(n) 
def is_valid(s):
    stack = []
    pairs = {
        ")": "(",
        "]": "[",
        "}": "{"
    }

    for char in s:
        if char in pairs:
            if not stack or stack[-1] != pairs[char]:
                return False
            stack.pop()
        else:
            stack.append(char)

    return not stack

Important Mental Model

Closing brackets are never pushed into the stack. Opening brackets are pushed. When a closing bracket appears, we compare it with the most recent unmatched opening bracket at stack[-1]. 

s = "(())"

char "(" -> push       stack = ["("]
char "(" -> push       stack = ["(", "("]
char ")" -> match/pop  stack = ["("]
char ")" -> match/pop  stack = []

Key vs Value

In if char in pairs, Python checks dictionary keys. The keys are closing brackets. pairs[char] returns the opening bracket that should be on top of the stack.

Interview Sentence

"I push opening brackets onto a stack. When I see a closing bracket, I check whether the stack top is the matching opening bracket. If not, the string is invalid. At the end, the stack must be empty."

LeetCode 2

Min Stack

Design a stack that supports push, pop, top, and getMin in O(1).

Key Idea

Use two stacks: one for actual values and one for the minimum value at each stack depth. 

stack     = [5, 2, 8, 1]
min_stack = [5, 2, 2, 1]

Two-Stack Solution

All operations O(1) 
class MinStack:

    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, val):
        self.stack.append(val)

        if not self.min_stack:
            self.min_stack.append(val)
        else:
            current_min = min(val, self.min_stack[-1])
            self.min_stack.append(current_min)

    def pop(self):
        self.stack.pop()
        self.min_stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.min_stack[-1]

Why Pop Both?

The two stacks represent the same depth. If one value is removed from stack, the matching minimum snapshot must also be removed from min_stack.

Interview Sentence

"I use two stacks. The main stack stores actual values, and the min stack stores the minimum value at each depth. When I push, I push the smaller of the new value and previous minimum. When I pop, I pop both stacks."

System Design Basics

Database Index

A database index is like a book index. It helps the database find rows faster without scanning every row.

Example

SELECT * FROM users
WHERE email = 'alex@example.com';

CREATE INDEX idx_users_email
ON users(email);

Benefits

WHEREFind matching rows faster.
ORDER BYHelp with sorted reads.
JOINSpeed up lookups across related tables.

Tradeoffs

Indexes need extra storage and can slow down writes because inserts, updates, and deletes may also need to update the index.

Interview Sentence

"A database index helps the database find rows faster, similar to an index in a book. It improves read performance for queries using WHERE, ORDER BY, or JOIN columns, but it costs extra storage and can slow down writes."

Must-Memorize Q&A

Concepts You Should Be Able to Say Out Loud

What is a stack?

A Last-In, First-Out data structure.

What does stack[-1] mean?

It means the top item of the stack without removing it.

In Valid Parentheses, does the stack store closing brackets?

No. It only stores opening brackets. Closing brackets are compared against the stack top.

Why does Valid Parentheses return not stack?

Every opening bracket must be matched and popped by the end.

How does Min Stack return the minimum in O(1)?

It keeps a second stack storing the minimum value at each depth.

What is a database index?

A data structure that helps the database find rows faster.
