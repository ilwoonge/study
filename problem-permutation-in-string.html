Permutation in String

Check whether s2 contains a substring that is a permutation of s1.

PatternFixed-size Sliding Window
TimeO(n)
SpaceO(1)

Interpretation

A permutation has the same length and the same character counts. Therefore, every candidate window in s2 must have length len(s1).

Optimized Solution

O(n)
def check_inclusion(s1, s2):
    if len(s1) > len(s2):
        return False

    s1_count = {}
    window_count = {}

    for char in s1:
        s1_count[char] = s1_count.get(char, 0) + 1

    left = 0

    for right in range(len(s2)):
        char = s2[right]
        window_count[char] = window_count.get(char, 0) + 1

        if right - left + 1 > len(s1):
            left_char = s2[left]
            window_count[left_char] -= 1

            if window_count[left_char] == 0:
                del window_count[left_char]

            left += 1

        if window_count == s1_count:
            return True

    return False

Walkthrough

For s1 = "ab" and s2 = "eidbaooo", the window "ba" has the same frequency map as "ab", so the answer is True.

Interview Answer

"I use a fixed-size Sliding Window of length len(s1). I keep a frequency map for s1 and for the current window. If the maps match, the current window is a permutation."
