LC Contains Duplicate Set lookup for duplicates
Problem BankDay 1

LeetCode

Contains Duplicate

Return true if any value appears at least twice in the array.

PatternSet lookup
TimeO(n)
SpaceO(n)

Interpretation

The question is simply: "Have I seen this number before?" Because we only need existence, not an index or count, a Set is the cleanest tool.

Optimized Solution

O(n)
def contains_duplicate(nums):
    seen = set()

    for num in nums:
        if num in seen:
            return True

        seen.add(num)

    return False

Walkthrough

For [1, 2, 3, 1], we add 1, 2, and 3 to the Set. When we see 1 again, it is already in the Set, so we return True.

Interview Answer

"I use a Set to store numbers I have already seen. For each number, I check whether it exists in the Set. If it does, I return true. Otherwise, I add it. Since Set lookup and insertion are average O(1), the total time is O(n), and the space is O(n)."
