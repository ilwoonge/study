Day 9 Upgrade

Today, the window is not only a range. It also has character counts. We use those counts to decide whether the window is valid.

LeetCode 1

Longest Repeating Character Replacement

Find the longest substring that can become all one repeated character after replacing at most k characters.

Key Formula

The number of replacements needed is the window length minus the count of the most frequent character. 

replacements_needed = window_length - max_freq

valid window:
window_length - max_freq <= k

Sliding Window Solution

Time O(n) 
def character_replacement(s, k):
    counts = {}
    left = 0
    max_freq = 0
    longest = 0

    for right in range(len(s)):
        char = s[right]
        counts[char] = counts.get(char, 0) + 1
        max_freq = max(max_freq, counts[char])

        window_length = right - left + 1

        while window_length - max_freq > k:
            left_char = s[left]
            counts[left_char] -= 1
            left += 1
            window_length = right - left + 1

        longest = max(longest, window_length)

    return longest

Why the Formula Works

If the most common character appears max_freq times, every other character in the window must be replaced. That count is window_length - max_freq. 

window = "AABA"

A: 3
B: 1

window_length - max_freq = 4 - 3 = 1

Interview Sentence

"I keep character counts inside the current window. The window is valid if its length minus the most frequent character count is at most k. If it needs more than k replacements, I shrink from the left."

LeetCode 2

Permutation in String

Check whether s2 contains a substring that is a permutation of s1.

Key Idea

A permutation has the same length and the same character counts. So we slide a fixed-size window of length len(s1) across s2.

Fixed-Size Window Solution

Time O(n) 
def check_inclusion(s1, s2):
    if len(s1) > len(s2):
        return False

    s1_count = {}
    window_count = {}

    for char in s1:
        s1_count[char] = s1_count.get(char, 0) + 1

    left = 0

    for right in range(len(s2)):
        char = s2[right]
        window_count[char] = window_count.get(char, 0) + 1

        if right - left + 1 > len(s1):
            left_char = s2[left]
            window_count[left_char] -= 1

            if window_count[left_char] == 0:
                del window_count[left_char]

            left += 1

        if window_count == s1_count:
            return True

    return False

Example

s1 = "ab"
s2 = "eidbaooo"

windows of length 2:
"ei", "id", "db", "ba"

"ba" has the same counts as "ab"
answer = True

Interview Sentence

"I use a fixed-size Sliding Window of length len(s1). I compare the frequency map of the current window with the frequency map of s1. If they match, that window is a permutation."

System Design Basics

CDN

A CDN, or Content Delivery Network, caches content on edge servers closer to users.

Basic Flow

User -> Nearby CDN Edge -> Origin Server

1. User requests an image, CSS, JS, or video
2. Nearby edge server checks its cache
3. If cached, edge returns it quickly
4. If not cached, edge fetches from origin
5. Edge stores it for future requests

Why Use a CDN?

latencyServe content from a location closer to the user.
origin loadReduce repeated traffic to the origin server.
global scaleImprove response time for users in many regions.
static contentWorks especially well for images, CSS, JS, and videos.

CDN vs Cache

A CDN is a type of cache, but it is distributed geographically. The main advantage is serving content from edge servers near users.

Interview Sentence

"A CDN is a distributed network of edge servers that caches static content close to users. It reduces latency and decreases load on the origin server."

Must-Memorize Q&A

Concepts You Should Be Able to Say Out Loud

What is the key formula in Character Replacement?

window_length - max_freq <= k.

What does window_length - max_freq mean?

It is the number of characters we must replace to make the entire window one repeated character.

Why shrink the window in Character Replacement?

Because if replacements needed is greater than k, the current window is invalid.

Why is the window fixed-size in Permutation in String?

A permutation must have the same length and same character counts as s1.

How do we know a window is a permutation?

The current window frequency map equals the frequency map of s1.

What is a CDN?

A distributed network of edge servers that caches content closer to users.
