Two Sum II - Input Array Is Sorted

Find two values in a sorted array that add up to the target and return their 1-based indexes.

PatternTwo Pointers
TimeO(n)
SpaceO(1)

Interpretation

This is different from regular Two Sum because the input is already sorted. Sorted order lets us decide which pointer to move.

Optimized Solution

O(n)
def two_sum(numbers, target):
    left = 0
    right = len(numbers) - 1

    while left < right:
        current_sum = numbers[left] + numbers[right]

        if current_sum == target:
            return [left + 1, right + 1]

        if current_sum < target:
            left += 1
        else:
            right -= 1

Walkthrough

For [2, 7, 11, 15] and target 9, the first sum is 17, which is too large, so move right left. Then 2 + 7 = 9, so return [1, 2].

Interview Answer

"Because the array is sorted, I use two pointers. If the sum is too small, I move the left pointer to increase it. If the sum is too large, I move the right pointer to decrease it. The returned indexes are 1-based, so I add one to each pointer."
