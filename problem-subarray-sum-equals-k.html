Subarray Sum Equals K

Count how many continuous subarrays have a sum exactly equal to k, even when the array contains negative numbers.

PatternPrefix sum + HashMap
TimeO(n)
SpaceO(n)

Interpretation

A prefix sum is the total from the start of the array up to the current index. If the current prefix sum is prefix_sum, then we need a previous prefix sum equal to prefix_sum - k. Removing that previous total leaves a middle subarray whose sum is exactly k. 

current prefix - previous prefix = k
previous prefix = current prefix - k

Optimized Solution

O(n)
def subarray_sum(nums, k):
    prefix_count = {0: 1}
    prefix_sum = 0
    answer = 0

    for num in nums:
        prefix_sum += num

        target = prefix_sum - k
        answer += prefix_count.get(target, 0)

        prefix_count[prefix_sum] = prefix_count.get(prefix_sum, 0) + 1

    return answer

Walkthrough

For nums = [1, 2, 3, 1, 1, 1] and k = 3, the matching subarrays are [1, 2], [3], and [1, 1, 1]. When the final prefix sum is 9, the target is 6. Since prefix sum 6 appeared after [1, 2, 3], the remaining suffix [1, 1, 1] has sum 3.

Why Count Frequencies?

The same prefix sum can appear more than once, especially when the array has zero or negative numbers. If a target prefix appeared multiple times, each occurrence creates a different valid subarray, so we add prefix_count.get(target, 0), not just 1.

Why Start with {0: 1}?

This represents the empty prefix before the array starts. It lets us count subarrays that begin at index 0, such as [1, 2] when k = 3.

Interview Answer

"I keep a running prefix sum and a HashMap that counts how many times each prefix sum has appeared. For each number, I check how many previous prefixes equal current prefix minus k. Each one forms a subarray ending at the current index with sum k. Then I record the current prefix sum. This is O(n) time and O(n) space."
