Encode and Decode Strings

Serialize a list of strings into one string and deserialize it back without losing information.

PatternLength-prefix encoding
TimeO(n)
SpaceO(n)

Interpretation

A delimiter alone is unsafe because the delimiter can appear inside a string. Instead, store each string as length + separator + content.

Length-Prefix Solution

O(n)
def encode(strs):
    result = ""

    for s in strs:
        result += str(len(s)) + "#" + s

    return result


def decode(s):
    result = []
    i = 0

    while i < len(s):
        j = i

        while s[j] != "#":
            j += 1

        length = int(s[i:j])
        word_start = j + 1
        word = s[word_start:word_start + length]

        result.append(word)
        i = word_start + length

    return result

Walkthrough

For "6#he#llo5#world", decode reads 6, then exactly six characters: he#llo. The inner # is safe because length controls parsing.

Interview Answer

"I use length-prefix encoding. For each string, I store its length, a separator, and the string. During decoding, I read the length first and then read exactly that many characters. This is safe even if the string contains the separator."
