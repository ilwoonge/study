LeetCode 1

Top K Frequent Elements

Given an integer array and an integer k, return the k most frequent elements.

Frequency Map + Sorting

Time O(n + m log m) 
def top_k_frequent(nums, k):
    count = {}

    for num in nums:
        count[num] = count.get(num, 0) + 1

    items = list(count.items())
    items.sort(key=lambda pair: pair[1], reverse=True)

    result = []
    for i in range(k):
        result.append(items[i][0])

    return result

n is the total number of elements, and m is the number of unique elements. Counting costs O(n). Sorting unique elements by frequency costs O(m log m).

LeetCode 2

Product of Array Except Self

For each index, return the product of every number except the number at that index, without using division.

Prefix + Suffix Solution

Time O(n) / Extra Space O(1) 
def product_except_self(nums):
    length = len(nums)
    result = [1] * length

    prefix = 1
    for i in range(length):
        result[i] = prefix
        prefix *= nums[i]

    suffix = 1
    for i in range(length - 1, -1, -1):
        result[i] *= suffix
        suffix *= nums[i]

    return result

Why This Works

The answer at index i is the product of everything to the left of i multiplied by the product of everything to the right of i. 

answer[i] = left_product[i] * right_product[i]

Interview Sentence

"I store prefix products in the output array during the first pass, then scan from right to left and multiply each position by the suffix product. This gives O(n) time without using division."

Python Pattern

Reverse Traversal

The suffix pass uses Python's reverse range pattern to iterate from the last valid index down to index 0.

Reverse Loop Visual

How to Read It

for i in range(length - 1, -1, -1):

Start at the last index, move backward by 1, and stop after index 0. The stop value is -1 because Python's range excludes the stop value.

Must-Memorize Q&A

Concepts You Should Be Able to Say Out Loud

These answers are designed for interview practice. Keep them short, clear, and tied to complexity.

How do you solve Top K Frequent Elements?

Build a frequency map from number to count, sort the unique numbers by frequency in descending order, and return the first k numbers.

What does m mean in O(n + m log m)?

m is the number of unique elements. We scan all n values, then sort only the unique values.

What is a prefix product?

A prefix product at index i is the product of all values before index i.

What is a suffix product?

A suffix product at index i is the product of all values after index i.

Why not use a nested loop for Product Except Self?

A nested loop recomputes products for every index and costs O(n^2). Prefix and suffix products reuse information and reduce the time to O(n).

How do you read range(length - 1, -1, -1)?

It starts at the last valid index, moves backward by 1 each time, and includes index 0 because the stop value -1 is excluded.

Why is Product Except Self O(1) extra space?

If the output array does not count as extra space, the algorithm only uses two variables, prefix and suffix.

What is the main Day 3 pattern?

Avoid repeated work. Count once when ranking frequency, and carry prefix/suffix information instead of recomputing products.
