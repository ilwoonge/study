LeetCode 1

Longest Consecutive Sequence

Given an unsorted list of numbers, find the length of the longest consecutive sequence, such as 1, 2, 3, 4.

Key Idea

A number is the start of a sequence only if num - 1 does not exist. Once we find a start, we count upward with num + 1, num + 2, and so on.

Set-Based Solution

Time O(n) 
def longest_consecutive(nums):
    num_set = set(nums)
    longest = 0

    for num in num_set:
        if num - 1 not in num_set:
            current = num
            length = 1

            while current + 1 in num_set:
                current += 1
                length += 1

            longest = max(longest, length)

    return longest

Why This Is O(n)

Each number is only expanded as part of a sequence once. We skip numbers that are not sequence starts, so the total amount of work across all while loops is linear.

Interview Sentence

"I put every number into a Set for O(1) average lookup. Then I only start counting from numbers whose previous value does not exist, because those are true sequence starts."

LeetCode 2

Reorder Data in Log Files

Letter logs come first and are sorted by content, then identifier. Digit logs stay in their original order and come after letter logs.

Sorting Rules

letter logsSort by content. If tied, sort by identifier.
digit logsKeep original relative order.
final resultSorted letter logs first, digit logs second.

Tuple Sorting Solution

O(n log n) 
def reorder_log_files(logs):
    letter_logs = []
    digit_logs = []

    for log in logs:
        identifier, content = log.split(" ", 1)

        if content[0].isdigit():
            digit_logs.append(log)
        else:
            letter_logs.append((content, identifier, log))

    letter_logs.sort()

    return [log for content, identifier, log in letter_logs] + digit_logs

Why Store a Tuple?

(content, identifier, log) lets Python sort by content first, identifier second, while still keeping the original full log string for the final answer.

Interview Sentence

"I split each log into identifier and content. Digit logs are kept in order, while letter logs are stored as tuples so Python sorts by content first and identifier second."

Python Concepts

Parsing, Tuples, and List Comprehension

These small Python details are important because they make the log solution clean and interview-friendly.

log.split(" ", 1)

Split the string by a space, but only split once. This separates the identifier from the rest of the log content. 

"let1 art can".split(" ", 1)

returns:
["let1", "art can"]

letter_logs.append((content, identifier, log))

This appends one tuple to the list. The tuple stores the sort key and the original log together. 

("art can", "let1", "let1 art can")

content     -> "art can"
identifier  -> "let1"
log         -> "let1 art can"

return [log for content, identifier, log in letter_logs] + digit_logs

The list comprehension extracts only the original log string from each sorted tuple. Then + digit_logs appends the digit logs to the end.

Must-Memorize Q&A

Concepts You Should Be Able to Say Out Loud

Why do we use a Set for Longest Consecutive Sequence?

A Set gives average O(1) lookup, so we can quickly check whether neighboring numbers exist.

How do we know a number starts a sequence?

If num - 1 is not in the Set, then num has no previous neighbor and starts a sequence.

Why is Longest Consecutive Sequence O(n)?

Each number is visited a constant number of times, and sequence expansion only starts at true starts.

What does split(" ", 1) do?

It splits the log into two parts at the first space: identifier and content.

Why do we store letter logs as tuples?

Python sorts tuples from left to right, so (content, identifier, log) naturally sorts by content, then identifier.

Why do digit logs keep their original order?

The problem requires digit logs to remain stable, so we append them to a separate list and add them after sorted letter logs.
