Generate Parentheses

Generate every valid combination of n pairs of parentheses by choosing one character at a time and blocking invalid paths early.

PatternBacktracking
ChoiceAdd ( or )
ConstraintKeep prefix valid

Interpretation

We are not checking one completed string. We are building all valid strings. At each recursive call, the current string must still be a possible prefix of a valid answer. 

n = 3

valid examples:
((()))
(()())
(())()
()(())
()()()

Optimized Solution

Backtracking
def generateParenthesis(n):
    result = []

    def backtrack(current, open_count, close_count):
        if len(current) == 2 * n:
            result.append(current)
            return

        if open_count < n:
            backtrack(current + "(", open_count + 1, close_count)

        if close_count < open_count:
            backtrack(current + ")", open_count, close_count + 1)

    backtrack("", 0, 0)
    return result

Why the Conditions Work

open_count < nPrevents using more than n opening parentheses.
close_count < open_countPrevents a closing parenthesis from appearing before a matching opening parenthesis.
len(current) == 2 * nMeans a complete valid string has been built.

Important Example

For n = 3, the string "((((((" cannot be created even though its length is six. The algorithm only allows three opening parentheses. 

open_count = 3
n = 3

open_count < n
3 < 3 -> False

Walkthrough

n = 2

""      -> add "("
"("     -> add "("
"(("    -> add ")"
"(()"   -> add ")"  => "(())"

"("     -> add ")"
"()"    -> add "("
"()("   -> add ")"  => "()()"

Interview Answer

"I use backtracking to generate every valid string. I keep the current string and the counts of opening and closing parentheses. I add an opening parenthesis only if I have used fewer than n, and I add a closing parenthesis only if there is an unmatched opening parenthesis. When the string length reaches 2n, I save it."
