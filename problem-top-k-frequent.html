Top K Frequent Elements

Return the k most frequent elements from an integer array.

PatternCount, then rank
TimeO(n + m log m)
SpaceO(m)

Interpretation

First count how often each number appears. Then rank the unique numbers by their counts and return the first k.

Frequency Map + Sorting

Simple optimized path
def top_k_frequent(nums, k):
    count = {}

    for num in nums:
        count[num] = count.get(num, 0) + 1

    items = list(count.items())
    items.sort(key=lambda pair: pair[1], reverse=True)

    result = []
    for i in range(k):
        result.append(items[i][0])

    return result

Complexity

Counting all values costs O(n). If there are m unique values, sorting them costs O(m log m). Total time is O(n + m log m).

Interview Answer

"I first build a frequency map from number to count. Then I sort the unique numbers by frequency in descending order and return the first k numbers. Counting is O(n), sorting the unique values is O(m log m), so the total time is O(n + m log m)."
