LC 3Sum Sort, two pointers, and duplicates
Problem Bank Day 7

LeetCode

3Sum

Return all unique triplets where the sum of three numbers is zero.

PatternSort + Two Pointers
TimeO(n^2)
SpaceO(1) excluding output

Interpretation

We need combinations, not indexes. The same triplet should appear only once, even if the input contains duplicate numbers.

Optimized Solution

O(n^2)
def three_sum(nums):
    nums.sort()
    result = []

    for i in range(len(nums)):
        if i > 0 and nums[i] == nums[i - 1]:
            continue

        left = i + 1
        right = len(nums) - 1

        while left < right:
            total = nums[i] + nums[left] + nums[right]

            if total == 0:
                result.append([nums[i], nums[left], nums[right]])

                left += 1
                right -= 1

                while left < right and nums[left] == nums[left - 1]:
                    left += 1

                while left < right and nums[right] == nums[right + 1]:
                    right -= 1

            elif total < 0:
                left += 1

            else:
                right -= 1

    return result

Walkthrough

For [-1, 0, 1, 2, -1, -4], sort into [-4, -1, -1, 0, 1, 2]. When the fixed value is -1, the two pointers find [-1, -1, 2] and [-1, 0, 1].

Duplicate Logic

Skip duplicate fixed values before starting the two-pointer search. After finding a valid triplet, move both pointers and skip repeated left and right values so the same triplet is not added again.

Interview Answer

"I sort the array, then fix one number and use two pointers to find the other two. If the sum is too small, I move left. If the sum is too large, I move right. I skip duplicates for the fixed value and after finding a triplet so the result contains only unique triplets."
