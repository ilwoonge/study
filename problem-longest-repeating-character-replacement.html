Longest Repeating Character Replacement

Find the longest substring that can become one repeated character after replacing at most k characters.

PatternSliding Window
TimeO(n)
SpaceO(1)

Interpretation

For any window, keep the most frequent character and replace all other characters. The window is valid if those replacements fit within k.

Optimized Solution

O(n)
def character_replacement(s, k):
    counts = {}
    left = 0
    max_freq = 0
    longest = 0

    for right in range(len(s)):
        char = s[right]
        counts[char] = counts.get(char, 0) + 1
        max_freq = max(max_freq, counts[char])

        window_length = right - left + 1

        while window_length - max_freq > k:
            left_char = s[left]
            counts[left_char] -= 1
            left += 1
            window_length = right - left + 1

        longest = max(longest, window_length)

    return longest

Key Formula

window_length - max_freq is the number of characters that must be replaced. If it is greater than k, shrink the window.

Interview Answer

"I use a Sliding Window and count character frequencies. The number of replacements needed is the window length minus the most frequent character count. If that number is greater than k, I shrink from the left."
