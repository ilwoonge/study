LeetCode 150

Evaluate Reverse Polish Notation

Reverse Polish Notation places the operator after its operands. A stack is a natural fit because each operator needs the most recent two numbers.

Normal Expression vs RPN

Normal expression:
(2 + 1) * 3

Reverse Polish Notation:
2 1 + 3 *

When the + appears, it uses 2 and 1. When the * appears, it uses the result 3 and the next number 3.

Stack Rule

NumberPush it onto the stack.
OperatorPop two numbers, calculate, and push the result.
EndThe final stack value is the answer.

Why Order Matters

tokens = ["4", "2", "-"]
stack  = [4, 2]

b = stack.pop()  # 2
a = stack.pop()  # 4

a - b = 4 - 2 = 2

Addition and multiplication can be reversed, but subtraction and division must keep the original operand order.

Optimized Code

One-Pass Stack Solution

Each token is processed once. The stack stores intermediate values until an operator is ready to combine them.

Python Solution

Time O(n), Space O(n) 
def evalRPN(tokens):
    stack = []

    for token in tokens:
        if token not in "+-*/":
            stack.append(int(token))
        else:
            b = stack.pop()
            a = stack.pop()

            if token == "+":
                stack.append(a + b)
            elif token == "-":
                stack.append(a - b)
            elif token == "*":
                stack.append(a * b)
            else:
                stack.append(int(float(a) / b))

    return stack[0]

Division Detail

LeetCode expects division to truncate toward zero. In Python, // floors negative results, so use int(float(a) / b) for Python 2 style submissions. 

6 / -132 = -0.045...
truncate toward zero = 0

6 // -132 = -1  # not correct for this problem

Walkthrough

tokens = ["2", "1", "+", "3", "*"]

2 -> push [2]
1 -> push [2, 1]
+ -> pop 1 and 2, push 3
3 -> push [3, 3]
* -> pop 3 and 3, push 9

Interview Sentence

"I use a stack because each operator in RPN consumes the most recent two operands. I push numbers, pop two values when I see an operator, apply the operator in order, and push the result back."

System Design

Database Replication

Replication copies data from one database node to another. It helps systems handle more read traffic and survive database failures.

Primary and Replica

Write traffic:
User -> App Server -> Primary DB

Read traffic:
User -> App Server -> Replica DB

The primary database handles writes. Replica databases are usually used to serve reads and reduce load on the primary.

Why Use Replicas?

Scale readsSpread read queries across multiple databases.
AvailabilityKeep serving traffic if one database node fails.
PerformancePlace replicas closer to users or heavy workloads.

Replication Lag

Replication lag is the delay between a write on the primary and the same data appearing on a replica. This means a replica can briefly return stale data.

AWS Mapping

Relational read scaling -> Amazon RDS Read Replicas
Aurora read scaling     -> Aurora Replicas
Key-value scale         -> DynamoDB global tables
Cache layer             -> ElastiCache

Consistency Tradeoff

Strong vs Eventual Consistency

Consistency describes what a user is allowed to see after data is written. Different features need different guarantees.

Strong Consistency

After a write succeeds, future reads return the latest value. Use this for critical data where stale reads can cause real problems. 

Good examples:
- Bank balance
- Payment status
- Order confirmation
- Inventory count

Eventual Consistency

Reads may briefly return older data, but replicas eventually catch up. This is often acceptable for high-scale, non-critical features. 

Good examples:
- Like count
- View count
- Feed ranking
- Analytics counters

Interview Sentence

"For critical data such as payments or balances, I would prefer strong consistency. For high-scale features like likes, views, or feeds, eventual consistency is often acceptable because it improves availability and scalability."

Must-Memorize Q&A

Concepts You Should Be Able to Say Out Loud

Why is a stack useful for RPN?

Because each operator needs the most recent two operands, and a stack gives direct access to the most recently added values.

Why do we pop b before a?

The last pushed number is the right operand. For subtraction and division, the calculation must be a - b or a / b.

Why not use // for division?

Python floor division rounds negative results downward, but this problem requires truncation toward zero.

Why do systems use database replicas?

Replicas help scale read traffic, improve availability, and reduce load on the primary database.

What is replication lag?

The delay between a write on the primary database and the same update appearing on a replica.

When is eventual consistency acceptable?

When stale data is temporarily acceptable, such as likes, views, feeds, or analytics counters.
