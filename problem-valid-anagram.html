Valid Anagram

Return true if two strings contain the same characters with the same counts.

PatternFrequency map
TimeO(n)
SpaceO(k)

Interpretation

Two strings are anagrams if every character appears the same number of times in both strings. So we count characters in one string and subtract using the other.

Optimized Solution

O(n)
def is_anagram(s, t):
    if len(s) != len(t):
        return False

    count = {}

    for ch in s:
        count[ch] = count.get(ch, 0) + 1

    for ch in t:
        if ch not in count:
            return False

        count[ch] -= 1

        if count[ch] < 0:
            return False

    return True

Key Line

count.get(ch, 0) + 1 means: get the current count for this character, use 0 if it has not appeared before, then add 1.

Interview Answer

"I first check if the strings have the same length. Then I build a frequency map for the first string. I iterate through the second string and decrement the count for each character. If a character is missing or its count becomes negative, I return false. Otherwise, the strings are anagrams. The time is O(n), and the space is O(k)."
