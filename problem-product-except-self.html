Product of Array Except Self

Return an array where each index contains the product of all numbers except the number at that index.

PatternPrefix + suffix
TimeO(n)
Extra SpaceO(1)

Interpretation

For each index, the answer is the product of everything on the left multiplied by the product of everything on the right. 

answer[i] = left_product * right_product

Prefix + Suffix Solution

O(n)
def product_except_self(nums):
    length = len(nums)
    result = [1] * length

    prefix = 1
    for i in range(length):
        result[i] = prefix
        prefix *= nums[i]

    suffix = 1
    for i in range(length - 1, -1, -1):
        result[i] *= suffix
        suffix *= nums[i]

    return result

Reverse Loop

range(length - 1, -1, -1) starts at the last valid index, moves backward by 1, and includes index 0 because Python excludes the stop value -1.

Interview Answer

"For each index, the answer is the left product times the right product. I store prefix products in the output array during the first pass. Then I scan from right to left and multiply each position by the suffix product. This gives O(n) time without using division, and O(1) extra space if the output array does not count."
