Valid Parentheses

Check whether every closing bracket matches the most recent unmatched opening bracket.

PatternStack
TimeO(n)
SpaceO(n)

Interpretation

Opening brackets are pushed. Closing brackets are not pushed; they must match the current stack top.

Optimized Solution

O(n)
def is_valid(s):
    stack = []
    pairs = {
        ")": "(",
        "]": "[",
        "}": "{"
    }

    for char in s:
        if char in pairs:
            if not stack or stack[-1] != pairs[char]:
                return False
            stack.pop()
        else:
            stack.append(char)

    return not stack

Walkthrough

s = "(())"

"(" -> push       stack = ["("]
"(" -> push       stack = ["(", "("]
")" -> match/pop  stack = ["("]
")" -> match/pop  stack = []

Interview Answer

"I use a stack to track opening brackets. When I see a closing bracket, I check whether the stack top is the matching opening bracket. At the end, the stack must be empty."
