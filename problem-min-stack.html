LeetCode

Min Stack

Design a stack that can return the current minimum value in constant time.

PatternStack design
TimeO(1) operations
SpaceO(n)

Interpretation

A normal stack cannot find the minimum in O(1). Add a second stack that stores the minimum value at each depth.

Two-Stack Solution

O(1)
class MinStack:

    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, val):
        self.stack.append(val)

        if not self.min_stack:
            self.min_stack.append(val)
        else:
            self.min_stack.append(min(val, self.min_stack[-1]))

    def pop(self):
        self.stack.pop()
        self.min_stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.min_stack[-1]

Walkthrough

push(5) -> stack [5],       min_stack [5]
push(2) -> stack [5, 2],    min_stack [5, 2]
push(8) -> stack [5, 2, 8], min_stack [5, 2, 2]

getMin() returns min_stack[-1] = 2

Interview Answer

"I use two stacks. The main stack stores values, and the min stack stores the minimum value at each depth. Because the current minimum is always on top of the min stack, getMin is O(1)."
