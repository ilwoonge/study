Pattern

Two Pointers

Two Pointers uses two indexes that move through an array or string. A common setup starts one pointer at the left side and one at the right side.

Basic Shape

left = 0
right = len(arr) - 1

while left < right:
    # compare or calculate something
    left += 1
    right -= 1

When to Use It

string comparisonCompare both ends, such as palindrome checks.
sorted arraysMove left or right based on whether the sum is too small or too large.
pair searchFind two values efficiently without checking every pair.

Interview Sentence

"I use two pointers when I can make progress from both ends of the input or when sorted order tells me which pointer to move."

LeetCode 1

Valid Palindrome

Check whether a string reads the same forward and backward after ignoring non-alphanumeric characters and case.

Key Idea

Move left and right inward. Skip spaces, punctuation, and symbols. Compare lowercase letters and digits.

Two Pointers Solution

Time O(n) 
def is_palindrome(s):
    left = 0
    right = len(s) - 1

    while left < right:
        while left < right and not s[left].isalnum():
            left += 1

        while left < right and not s[right].isalnum():
            right -= 1

        if s[left].lower() != s[right].lower():
            return False

        left += 1
        right -= 1

    return True

Walkthrough

For "A man, a plan, a canal: Panama", we ignore punctuation and spaces, compare lowercase characters from both ends, and eventually confirm that the cleaned sequence is a palindrome.

Interview Sentence

"I use two pointers from both ends. I skip non-alphanumeric characters, compare lowercase versions of valid characters, and move inward until the pointers meet."

LeetCode 2

Two Sum II - Input Array Is Sorted

Find two numbers in a sorted array that add up to the target. The answer uses 1-based indexes.

Why Sorting Matters

If the current sum is too small, move left right to increase the sum. If the current sum is too large, move right left to decrease the sum.

Two Pointers Solution

Time O(n) 
def two_sum(numbers, target):
    left = 0
    right = len(numbers) - 1

    while left < right:
        current_sum = numbers[left] + numbers[right]

        if current_sum == target:
            return [left + 1, right + 1]

        if current_sum < target:
            left += 1
        else:
            right -= 1

Example

numbers = [2, 7, 11, 15]
target = 9

left = 0  -> 2
right = 3 -> 15
sum = 17, too large, move right

left = 0  -> 2
right = 1 -> 7
sum = 9, return [1, 2]

Interview Sentence

"Because the array is sorted, I can use two pointers. If the sum is too small, I move the left pointer to get a larger value. If the sum is too large, I move the right pointer to get a smaller value."

System Design Basics

Load Balancer

A load balancer sits between clients and servers. It distributes incoming requests across multiple backend servers.

Basic Flow

Client
  |
  v
Load Balancer
  |------> Server A
  |------> Server B
  |------> Server C

Why We Need It

scalabilitySpread traffic across many servers.
availabilityRoute traffic away from unhealthy servers.
flexibilityAdd or remove servers without changing the client.
bottleneck controlPrevent one server from receiving all traffic.

Interview Sentence

"A load balancer distributes incoming traffic across multiple servers. It improves scalability and availability by preventing one server from becoming a bottleneck and by avoiding unhealthy servers."

Must-Memorize Q&A

Concepts You Should Be Able to Say Out Loud

What is the Two Pointers pattern?

It uses two indexes that move through an array or string to reduce unnecessary searching.

When should we use Two Pointers?

Use it for sorted arrays, pair search, or problems that compare both ends of a string or array.

Why does Two Sum II work with Two Pointers?

The array is sorted, so moving left increases the sum and moving right decreases the sum.

Why do we skip non-alphanumeric characters in Valid Palindrome?

The problem asks us to compare only letters and numbers.

Why does Two Sum II return left + 1 and right + 1?

The problem asks for 1-based indexes, while Python uses 0-based indexes.

What does a load balancer do?

It distributes incoming traffic across multiple servers to improve scalability and availability.
