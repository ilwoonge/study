LeetCode

3Sum

Find all unique triplets where a + b + c = 0. The important word is unique, so duplicate triplets must not appear in the answer.

Why Sort First?

Sorting lets us use two pointers. If the sum is too small, moving left right increases the sum. If the sum is too large, moving right left decreases the sum.

Optimized Solution

Time O(n^2) 
def three_sum(nums):
    nums.sort()
    result = []

    for i in range(len(nums)):
        if i > 0 and nums[i] == nums[i - 1]:
            continue

        left = i + 1
        right = len(nums) - 1

        while left < right:
            total = nums[i] + nums[left] + nums[right]

            if total == 0:
                result.append([nums[i], nums[left], nums[right]])

                left += 1
                right -= 1

                while left < right and nums[left] == nums[left - 1]:
                    left += 1

                while left < right and nums[right] == nums[right + 1]:
                    right -= 1

            elif total < 0:
                left += 1

            else:
                right -= 1

    return result

High-Level Flow

Fix one number with i. Then search for the other two numbers using left and right. This turns the problem into repeated Two Sum II searches. 

sorted nums = [-4, -1, -1, 0, 1, 2]

fixed = nums[i]
left = i + 1
right = len(nums) - 1

Example

nums = [-1, 0, 1, 2, -1, -4]

[-4, -1, -1, 0, 1, 2]

valid triplets:
[-1, -1, 2]
[-1, 0, 1]

Important Detail

Duplicate Skipping

3Sum is not only about finding sums. It is also about avoiding the same triplet more than once.

Skip Duplicate Fixed Values

If nums[i] is the same as nums[i - 1], using it again as the fixed value can generate the same triplets. 

if i > 0 and nums[i] == nums[i - 1]:
    continue

After Finding a Triplet

Once we find a valid triplet, we move both pointers inward. Then we skip repeated left and right values so the next answer is unique. 

left += 1
right -= 1

while left < right and nums[left] == nums[left - 1]:
    left += 1

while left < right and nums[right] == nums[right + 1]:
    right -= 1

Why Compare With Previous Left?

After left += 1, nums[left - 1] is the value we just used. If the new nums[left] is the same, it would create the same triplet again.

Why Compare With Next Right?

After right -= 1, nums[right + 1] is the value we just used. If the new nums[right] is the same, it would create the same triplet again.

Analysis

Complexity and Interview Answer

Time Complexity

Sorting takes O(n log n). The outer loop is O(n), and the two pointers scan the remaining array in O(n), so the main work is O(n^2).

Space Complexity

Excluding the output list, the algorithm uses O(1) extra space. Python sorting may use implementation-dependent temporary space.

Interview Sentence

"I sort the array first so I can use two pointers. Then I fix one number and search for the other two numbers with left and right pointers. I move left when the sum is too small and right when the sum is too large. I skip duplicate fixed values and duplicate pointer values to avoid repeated triplets."

System Design Basics

Horizontal Scaling vs Vertical Scaling

Scaling means increasing a system's ability to handle more traffic, users, or data.

Vertical Scaling

Make one server stronger by adding CPU, memory, storage, or using a larger machine. 

Small Server -> Bigger Server

Horizontal Scaling

Add more servers and distribute traffic across them, usually with a load balancer. 

          -> Server A
Client -> Load Balancer -> Server B
          -> Server C

Tradeoffs

verticalSimpler, but has hardware limits and a single-server failure risk.
horizontalMore scalable and available, but requires load balancing and coordination.

Interview Sentence

"Vertical scaling makes one server more powerful. Horizontal scaling adds more servers and distributes traffic across them. Horizontal scaling is usually better for large-scale systems because it improves scalability and availability."

Must-Memorize Q&A

Concepts You Should Be Able to Say Out Loud

Why do we sort the array in 3Sum?

Sorting lets us use two pointers and makes duplicate skipping easier.

Why does left += 1 make the sum bigger?

Because the array is sorted, moving left to the right gives a larger or equal value.

Why does right -= 1 make the sum smaller?

Because the array is sorted, moving right to the left gives a smaller or equal value.

Why skip duplicate nums[i] values?

To avoid using the same fixed value and generating repeated triplets.

What is the time complexity of 3Sum?

O(n^2), because for each fixed number, the two pointers scan the rest of the array.

What is the difference between vertical and horizontal scaling?

Vertical scaling makes one server stronger. Horizontal scaling adds more servers.
