Reorder Data in Log Files

Sort letter logs by content and identifier while keeping digit logs in their original order.

PatternCustom sorting
TimeO(n log n)
SpaceO(n)

Interpretation

Each log starts with an identifier. If the content after the identifier starts with a digit, it is a digit log. Otherwise, it is a letter log.

Optimized Solution

O(n log n)
def reorder_log_files(logs):
    letter_logs = []
    digit_logs = []

    for log in logs:
        identifier, content = log.split(" ", 1)

        if content[0].isdigit():
            digit_logs.append(log)
        else:
            letter_logs.append((content, identifier, log))

    letter_logs.sort()

    return [log for content, identifier, log in letter_logs] + digit_logs

Why split(" ", 1)?

It splits only at the first space, so the first part becomes the identifier and the second part keeps the full content unchanged.

"let1 art can".split(" ", 1)
returns ["let1", "art can"]

Why Store (content, identifier, log)?

Python compares tuples from left to right. That means the sort uses content first, then identifier. The original log is kept as the third value so we can return the exact original string.

Final Return

[log for content, identifier, log in letter_logs] extracts the original log string from each sorted tuple. Then + digit_logs places all digit logs after the letter logs.

Interview Answer

"I separate letter logs and digit logs. Digit logs keep their original order. For letter logs, I store a tuple of content, identifier, and original log, then sort the tuples. Finally, I extract the original log strings and append the digit logs."
