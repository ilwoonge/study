LeetCode

Longest Consecutive Sequence

Find the length of the longest consecutive number sequence in an unsorted array.

PatternSet lookup
TimeO(n)
SpaceO(n)

Interpretation

We are not asked to return the sequence itself. We only need the length of the longest run where each next number is one larger than the previous number.

Optimized Solution

O(n)
def longest_consecutive(nums):
    num_set = set(nums)
    longest = 0

    for num in num_set:
        if num - 1 not in num_set:
            current = num
            length = 1

            while current + 1 in num_set:
                current += 1
                length += 1

            longest = max(longest, length)

    return longest

Walkthrough

For [100, 4, 200, 1, 3, 2], the number 1 starts a sequence because 0 is missing. Then we count 2, 3, and 4, so the answer is 4.

Why O(n)

We only expand from real sequence starts. Although there is a nested while loop, each number is counted as part of a sequence once across the whole algorithm.

Interview Answer

"I store the numbers in a Set for average O(1) lookup. Then I only start counting from a number if its previous number does not exist, which means it is the beginning of a sequence. This avoids recounting the same sequence many times."
