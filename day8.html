Pattern

Sliding Window

Sliding Window manages a continuous range in an array or string using left and right pointers.

Core Idea

The right pointer usually expands the window by adding a new value. If the window becomes invalid, the left pointer moves forward to shrink the window. 

s = "abcabcbb"

window = s[left:right + 1]

When to Use It

longestLongest substring or subarray that satisfies a condition.
shortestSmallest continuous range that satisfies a condition.
maximum/minimumBest value inside a contiguous window.
substring/subarrayThe problem cares about a continuous range.

Interview Sentence

"I use Sliding Window when the problem asks about a continuous range. I expand with the right pointer, shrink with the left pointer when the window is invalid, and update the answer whenever the window is valid."

LeetCode 1

Best Time to Buy and Sell Stock

Find the maximum profit from one buy and one sell, where buying must happen before selling.

Key Idea

Track the lowest price seen so far as the best buying point. At each price, calculate the profit if we sell today.

One-Pass Solution

Time O(n) 
def max_profit(prices):
    min_price = float("inf")
    max_profit = 0

    for price in prices:
        if price < min_price:
            min_price = price

        profit = price - min_price
        max_profit = max(max_profit, profit)

    return max_profit

Why float("inf")?

It starts min_price as a value larger than any real stock price. That way, the first price we see will always become the initial minimum price. 

7 < float("inf")  # True

Walkthrough

prices = [7, 1, 5, 3, 6, 4]

price 7 -> min_price 7, profit 0
price 1 -> min_price 1, profit 0
price 5 -> min_price 1, profit 4
price 3 -> min_price 1, profit 2
price 6 -> min_price 1, profit 5

answer = 5

LeetCode 2

Longest Substring Without Repeating Characters

Find the length of the longest continuous substring that contains no repeated characters.

Substring vs Valid Substring

A substring only means a continuous piece of the original string. A valid substring for this problem must also have no repeated characters. 

s = "abcabcbb"

"bca" is valid:
continuous and no repeated characters

"cbb" is a substring:
continuous, but not valid because "b" repeats

Set-Based Sliding Window

Time O(n) 
def length_of_longest_substring(s):
    seen = set()
    left = 0
    longest = 0

    for right in range(len(s)):
        while s[right] in seen:
            seen.remove(s[left])
            left += 1

        seen.add(s[right])
        longest = max(longest, right - left + 1)

    return longest

Why Move left?

If s[right] already exists in the current window, the window has a duplicate. We remove characters from the left until the duplicate disappears.

Why right - left + 1?

Both indexes are included in the current window. If left = 1 and right = 3, the window covers indexes 1, 2, 3, so the length is 3.

Interview Sentence

"I use a Sliding Window with a Set. The right pointer expands the window. If the new character already exists, I move left and remove characters until the duplicate is gone. Then I update the longest valid window length."

System Design Basics

Cache

A cache stores frequently accessed data in a faster storage layer so the system does not need to repeatedly query the database.

Basic Flow

Client -> Server -> Cache -> Database

1. Server checks cache first
2. If found, return cached data
3. If not found, read from database
4. Store result in cache
5. Future requests become faster

Cache Hit vs Cache Miss

cache hitThe requested data is found in cache and returned quickly.
cache missThe data is not in cache, so the system reads from the database.

Why Use Cache?

latencyReturn frequently requested data faster.
database loadReduce repeated database reads.
scalabilityHandle more traffic with less backend pressure.

Important Tradeoff

Cached data can become stale. In interviews, mention invalidation, update strategy, and TTL when discussing cache design.

Must-Memorize Q&A

Concepts You Should Be Able to Say Out Loud

What is Sliding Window?

It is a pattern that manages a continuous range using left and right pointers.

When should we think about Sliding Window?

When the problem asks for the longest, shortest, maximum, or minimum contiguous subarray or substring.

What does min_price mean in the stock problem?

It means the lowest buying price seen so far.

Why use a Set in Longest Substring?

To quickly check whether the current window already contains a character.

Is "cbb" a valid substring for this problem?

No. It is a substring, but it is not valid because b repeats.

What is a cache hit?

A cache hit happens when requested data is found in the cache.

What is a cache miss?

A cache miss happens when requested data is not found in the cache.
