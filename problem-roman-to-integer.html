Roman to Integer

Convert a Roman numeral string into an integer by adding normal symbols and subtracting symbols that appear before larger ones.

PatternHashMap lookup
TimeO(n)
SpaceO(1)

Interpretation

Each Roman symbol has a fixed value. Usually we add values from left to right, but if the current value is smaller than the next value, the current symbol is part of a subtractive pair and should be subtracted. 

I = 1, V = 5, X = 10, L = 50
C = 100, D = 500, M = 1000

IV = 4, IX = 9, XL = 40
XC = 90, CD = 400, CM = 900

Optimized Solution

O(n)
def roman_to_int(s):
    values = {
        "I": 1,
        "V": 5,
        "X": 10,
        "L": 50,
        "C": 100,
        "D": 500,
        "M": 1000
    }

    total = 0

    for i in range(len(s)):
        current = values[s[i]]

        if i + 1 < len(s) and current < values[s[i + 1]]:
            total -= current
        else:
            total += current

    return total

Walkthrough

For MCMXCIV, we add M, subtract C before M, add M, subtract X before C, add C, subtract I before V, and add V. The total is 1994.

Interview Answer

"I map each Roman character to its integer value. Then I scan the string from left to right. If the current value is less than the next value, I subtract it; otherwise, I add it. This handles subtractive cases like IV and CM in one pass, so the time is O(n) and the space is O(1)."
