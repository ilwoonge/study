Valid Palindrome

Determine whether a string is a palindrome after ignoring punctuation, spaces, symbols, and case.

PatternTwo Pointers
TimeO(n)
SpaceO(1)

Interpretation

Compare only letters and numbers. Ignore punctuation and spaces. Treat uppercase and lowercase letters as the same.

Optimized Solution

O(n)
def is_palindrome(s):
    left = 0
    right = len(s) - 1

    while left < right:
        while left < right and not s[left].isalnum():
            left += 1

        while left < right and not s[right].isalnum():
            right -= 1

        if s[left].lower() != s[right].lower():
            return False

        left += 1
        right -= 1

    return True

Walkthrough

For "A man, a plan, a canal: Panama", the pointers skip commas, spaces, and the colon. The valid characters match from both ends, so the result is True.

Interview Answer

"I use two pointers from the start and end of the string. I skip non-alphanumeric characters, compare lowercase versions of valid characters, and return false as soon as a mismatch appears."
