Longest Substring Without Repeating Characters

Find the length of the longest continuous substring that has no repeated characters.

PatternSliding Window
TimeO(n)
SpaceO(k)

Interpretation

A substring is a continuous part of the original string. For this problem, the substring is valid only if it has no repeated characters.

Optimized Solution

O(n)
def length_of_longest_substring(s):
    seen = set()
    left = 0
    longest = 0

    for right in range(len(s)):
        while s[right] in seen:
            seen.remove(s[left])
            left += 1

        seen.add(s[right])
        longest = max(longest, right - left + 1)

    return longest

Walkthrough

For "abcabcbb", valid length-3 windows include "abc", "bca", and "cab". The substring "cbb" is continuous, but it is not valid because b repeats.

Interview Answer

"I use a Sliding Window with a Set to store characters in the current window. The right pointer expands the window. If the new character already exists, I move left and remove characters until the duplicate is gone. Then I update the longest window length."
