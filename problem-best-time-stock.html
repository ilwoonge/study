Best Time to Buy and Sell Stock

Find the maximum profit from one buy and one sell, where the buy must happen before the sell.

PatternSliding Window
TimeO(n)
SpaceO(1)

Interpretation

We need the best buy price before the current sell price. So while scanning prices, keep the lowest price seen so far.

Optimized Solution

O(n)
def max_profit(prices):
    min_price = float("inf")
    max_profit = 0

    for price in prices:
        if price < min_price:
            min_price = price

        profit = price - min_price
        max_profit = max(max_profit, profit)

    return max_profit

Walkthrough

For [7, 1, 5, 3, 6, 4], the lowest price becomes 1. Selling later at 6 gives profit 5, which is the best possible profit.

Interview Answer

"I track the minimum price seen so far as the best buying point. For each price, I calculate the profit if I sell today, then update the maximum profit. This works in one pass with O(n) time and O(1) space."
